# 04 · 课程与认证

> ⚠️ **先读这一段**：FDE 培训市场是 2026 年才快速涌入的，**绝大多数机构尚无真实的毕业成果数据**。付费前请务必按本文末尾的核查清单逐项验证。

## 一、核心课程对比

### FDE Academy（Futurense 旗下）

| 项目 | 信息 |
|------|------|
| **官网** | https://www.fde.academy/ |
| **形式** | 8 个月 PGP in FDE & Applied AI Solutions |
| **课程结构** | 32 周，四阶段，双轨（技术 + 咨询） |
| **认证** | 含 IIT 认证模块（IIT Modules） |
| **地点** | 线上 + 两日 Goa 线下 retreat |
| **规模** | 限额约 80 席，录取率约 4% |
| **录取门槛** | 平均 8.8 年经验（Senior 定位） |
| **费用** | 官网未公开 |

**四阶段设计**

| 阶段 | 周次 | 技术轨 | 咨询轨 | 产出物 |
|------|------|--------|--------|--------|
| 1. Foundations | 1–4 | Python、Git、现代 AI 工具 | 理解业务问题、提示模式与 API | 第一个可用的 AI 工具 + 问题陈述 |
| 2. Core Build | 5–12 | LLM 应用与工作流、上下文工程、RAG 基础 | 需求发现、PRD 与方案设计文档 | 可部署的 AI 系统 + 架构视图 |
| 3. Deployment Depth | 13–20 | 高级检索、RAG、评估与监控 | 干系人对齐、交付规划与迭代周期 | 生产级系统 + 交付文档 |
| 4. Capstone | 21–32 | MCP 工具与策略、生产部署、多 Agent 设计 | 端到端engagement 模拟、案例写作 | 2 个完整项目 + 5 篇案例 + 现场演示的 capstone |

**核心卖点**
- 真实 brief（Stripe、Salesforce、Razorpay 等），非模拟
- 自训练并自托管一个 SLM
- FDE Lab™ 框架（商标），先掌握 10+ 专有框架，再在 30+ GenAI 工具中应用
- 结业作品集导向：面试可用的部署系统 + 案例叙述 + 架构讲解

### Platypus Technologies · FDE Academy（企业侧）

这个和上面两个**性质完全不同** —— 它不是教个人转型，而是**帮企业建 FDE 能力**。

| 项目 | 信息 |
|------|------|
| **官网** | https://platypustech.xyz/ |
| **定位** | 为咨询公司与技术服务商设计 FDE 培养项目 |
| **方法** | 真实部署场景 + 现场辅导 + 回到工作中应用，**不做脱离实际工作的课堂教学** |
| **创始人** | Anjor Kanekar，其 Palantir FDE 复盘被 The Pragmatic Engineer 专文报道（该newsletter 读者超 50 万工程师） |

**三项核心服务**
1. **Advisory 咨询** — 评估现有或提议中的 FDE 职能，明确它该负责什么、如何与产品和销售协作、如何衡量成功。通常从**两周的 FDE Readiness Assessment** 开始
2. **Hiring 招聘** — 设计岗位画像、面试循环、练习题与校准标准
3. **FDE Academy** — 为咨询与技术服务商设计定制培养项目

**开源可读**：[anjor/fde-advisory-materials](https://github.com/anjor/fde-advisory-materials) —— 方法论材料全部开源，包括 FDE Blueprint 框架与实操模板。

## 二、其他相关课程与能力建设

### FDE Academy（Futurense）企业服务线
https://fde.academy/hire-train-deploy-fde-talent

提供两条路径：
- **Hire FDE Talent** —— 从精选人才池招聘
- **Build FDE Capability In-House** —— 培养内部高潜工程师，或按企业技术栈与 AI 部署需求定制 cohort

**关键调研数据**（与 AIM Research 联合）：
> **95%** 的组织报告有 FDE 能力需求，仅 **45%** 报告能获得所需人才。
> 供需缺口是当前 FDE 市场的核心结构性矛盾。

**人才池覆盖的岗位**：AI/ML Engineer、GenAI Engineer、Solutions Architect、AI Product Engineer、DevOps Engineer、Cloud Engineer、LLM Engineer、Technical Consultant。

## 三、免费替代方案（推荐优先）

**在考虑付费之前，先确认这些免费资源是否已够用：**

| 资源 | 能替代什么 |
|------|-----------|
| [Awesome-FDE-Roadmap](https://github.com/pierpaolo28/Awesome-FDE-Roadmap) | 完整知识地图 —— 它本身就覆盖了大部分课程的知识内容 |
| [the-fde-handbook](https://github.com/RichardXu001/the-fde-handbook) | 中文实战手册 |
| [ai-engineer-notebooks](https://github.com/calmrocks/ai-engineer-notebooks) | 动手实验 |
| [fde-gym](https://github.com/deeplethe/fde-gym) | 真实客户交付案例练习 |
| [100 个作品集项目](https://github.com/vivianaranha/Forward-Deployed-Engineer) | 作品集素材 |

**判断标准**：如果一个课程的主要卖点是「提供路线图 + 学习资料」，而这些资料在 GitHub 上都是开源的，那么该课程的付费价值主要在**社群、导师反馈与项目评审**上 —— 值得为这些付费，但要知道自己在为什么付费。

## 四、付费前核查清单

鉴于行业混乱，**建议逐项核查后再付款**：

### 关于机构
- [ ] 机构成立多久？FDE 课程是 2026 年才开的，机构历史与课程历史是两回事
- [ ] **导师是否真的是一线 FDE？** 查他们的 LinkedIn 是否有真实的 Palantir / OpenAI / Anthropic 等任职经历
- [ ] 有没有可验证的**真实学员作品集**（GitHub 链接而非宣传图）

### 关于数据
- [ ] 「毕业薪资 X 万」的样本量是多少？
- [ ] 薪资是**实际拿到 offer 的数据**，还是从岗位 JD 反推的**预测值**？
- [ ] 有没有公布分母（报名多少人、毕业多少人、就业多少人）？

### 关于承诺
- [ ] 就业保证条款写在哪？退款条件是什么？
- [ ] 「录取率 4%」听起来是筛选严格，但也可能是「报名基数小」的算术结果

### 行业共性事实（2026）
- FDE 岗位在 2025–2026 爆发，**绝大多数机构是在需求爆发后才开的课**
- a16z 将这类趋势称为 **"title arbitrage"**（头衔套利）—— 把解决方案工程或集成岗位换个名字以显示重要性
- 部分机构把 FDE 包装为「AI 时代最稀缺岗位」，但岗位本身是否真的稀缺，需看具体市场的招聘数据

> 🔍 **第三方可参考**：Ultralab 发布了 [Scaler vs FDE Academy 对比](https://www.appliedaicourse.com/blog/scaler-vs-fde-academy-comparison-for-the-forward-deployed-engineer-role)，可作为第三方视角的入门。

## 五、值得肯定的做法

不是所有付费课程都该被否定。以下做法在行业内属于相对诚实：

**1. 明确标注「不是转职保证」**
[alphalab.site](https://www.alphalab.site/forward-deployed-engineer) 的表述值得借鉴：
> 「目标不是保证转职，而是做出一个真人用过、失败被记录、成效可被量的部署案例。」
> 「12 周不是转职保证，而是一套做出第一个真实部署案例的交付节奏。」

**2. 公开席位数量与录取率**
FDE Academy 公开 80 席限额、约 4% 录取率、平均 8.8 年经验 —— 即使这些数字可能来自小基数，但**公开本身是诚实的信号**。

**3. 提供可验证的作品集要求**
要求 `discovery-brief.md`、`acceptance-criteria.md`、`evals/results.json`、`runbook.md`、`incident-postmortem.md` —— 这种**具体的交付物清单**比「产出企业级项目」这种模糊表述可靠得多。

**4. 明确能力缺口数据**
FDE Academy 公开「95% 有需求 / 45% 能获得人才」的调研（哪怕是自家调研），至少比「行业前景无限」这种话有信息量。

## 六、证书与认证的实际价值

**目前不存在被广泛认可的「FDE 官方认证」。**

原因：
1. 岗位本身 2025–2026 才爆发
2. 各家公司的 JD 要求差异极大 —— Dexity 数据显示 187 份 JD 中 Python 出现率 60%（且常作为默认假设不写出来），API 集成 19%，前端仅 10%
3. 这个岗位「按证据招聘」—— **可展示的部署案例 > 证书**

**更有效的替代验证方式**：
| 方式 | 强度 |
|------|------|
| 一个真实部署在你真实数据上跑过，且能讲清为什么这么设计、什么时候坏的 | ⭐⭐⭐ 最强 |
| 公开发布的完整案例仓库（含 evals、runbook、事故复盘） | ⭐⭐⭐ |
| 模拟环境（fde-gym）的练习记录 | ⭐⭐ |
| 通过 FDE 面试（三轮，含客户模拟） | ⭐⭐⭐ |
| 课程证书 | ⭐ 边际价值有限 |

## 七、快速结论

| 你的情况 | 建议 |
|---------|------|
| **想先了解这个岗位** | 别付费。读 [The New Stack](https://thenewstack.io/forward-deployed-engineers-ai/) + [Awesome-FDE-Roadmap](https://github.com/pierpaolo28/Awesome-FDE-Roadmap) 就够了 |
| **已有工程基础，想补客户交付技艺** | 免费资源 + [fde-gym](https://github.com/deeplethe/fde-gym) 实战。付费的边际价值最低 |
| **完全转行，需要结构与反馈** | 付费有道理，但要按核查清单严格验证，重点看**导师真实背景**与**学员作品集** |
| **企业要建 FDE 团队** | [Platypus](https://platypustech.xyz/) 的方法论材料是开源的，先读，再决定是否付费 |
| **只是想拿个证** | 不建议。这个岗位看的是作品，不是证书 |
